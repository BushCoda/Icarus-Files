# Contributing to Icarus Modding Research

Thanks for helping improve this repository and support the broader Icarus modding community.

This project is a research and documentation hub. Contributions should be factual, well-documented, and useful to other modders.

---

## Ways to Contribute

You can contribute by:
- Adding research notes or findings
- Correcting inaccurate information
- Improving organization and documentation
- Suggesting new topics or project categories
- Sharing community project submissions for the showcase
- Reporting issues with existing documentation or research

---

## Contribution Standards

### Research Quality
- Include the game version/build being discussed
- State how the finding was observed or extracted
- Explain the method or tool used
- Clearly label conclusions as:
  - Observed
  - Inferred
  - Experimentally verified

### Evidence Requirements
A useful contribution should include:
- What was observed
- How it was tested or extracted
- Whether it is supported by code, game behavior, or external research
- Any caveats or uncertainty

### Attribution
- Credit original authors when referencing their work
- Respect project ownership and repository rights
- Don’t submit content you do not have permission to redistribute

---

## Pull Request Guidelines

When submitting a PR:
- Keep changes organized and focused
- Use clear titles and concise descriptions
- Reference the relevant research or topic being updated
- Include screenshots, evidence, or links when helpful
- Avoid large unrelated changes

---

## Issues

Open an issue if you want to:
- Report a correction
- Ask a question
- Suggest a missing research topic
- Propose a new project for the community showcase

Please include:
- A clear description
- Relevant game version/build
- Any evidence or references
- A suggested fix or improvement if applicable

---

## Community Showcase Submissions

If you want your project featured:
- Add it to the [Community Project Showcase](COMMUNITY_SHOWCASE.md)
- Include your GitHub repo URL and short description
- Make sure it is relevant to Icarus modding, research, or tools
- Keep ownership with your own repository

---

## Important Notes

- Do not share proprietary game data or assets you do not have permission to redistribute
- Do not claim certainty without evidence
- Keep the repo professional, respectful, and focused on useful information

Thank you for helping build a stronger Icarus modding knowledge base.
